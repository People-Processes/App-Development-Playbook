## 4. Desired behavior

What happens instead, step by step. Name the screens and the buttons. A person who has
never seen the code should be able to picture the screen.

> If this is going to be handed to an AI tool to build, write this section in two layers.
> **Layer 1, the plain-English guide:** in one line / what this is / why it matters /
> what you will be able to do / how it fits / done when.
> **Layer 2, the build spec:** goal / current state, with files and functions / numbered
> scope / do not break / acceptance criteria / dependencies and sequencing / test notes /
> source references.
> Layer 1 first, always. If you cannot write it, the request is not understood well enough
> to build.
